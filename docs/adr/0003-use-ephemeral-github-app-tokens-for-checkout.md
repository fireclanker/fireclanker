# Use ephemeral GitHub App tokens for repository checkout

Public Source Repositories are checked out without credentials. On first deployment, the operator creates a private, organization-owned GitHub App through GitHub's manifest flow, and Fireclanker stores its credentials directly as an AWS Systems Manager Parameter Store SecureString. Private Source Repositories use short-lived, repository-scoped installation tokens minted by the queue worker; the separately launched agent microVM role cannot decrypt the parameter. The token is passed separately from persisted Agent Run data, exposed only to the clone process, and removed before OpenCode starts; it is never embedded in the Agent Prompt, clone URL, repository configuration, logs, or results. This preserves normal Git checkout semantics without intentionally granting the unattended agent a reusable GitHub credential, and avoids sharing a Fireclanker-wide private key across customer AWS accounts.
