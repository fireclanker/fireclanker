# Use ephemeral GitHub App tokens for repository checkout

Public Source Repositories are checked out without credentials. Private Source Repositories use short-lived, repository-scoped GitHub App installation tokens minted by the queue worker from a private key held in AWS Secrets Manager; the separately launched agent microVM role cannot read that key. The token is passed separately from persisted Agent Run data, exposed only to the clone process, and removed before OpenCode starts; it is never embedded in the Agent Prompt, clone URL, repository configuration, logs, or results. This preserves normal Git checkout semantics without intentionally granting the unattended agent a reusable GitHub credential, and avoids the broad scope and long lifetime of personal access tokens or SSH keys.
